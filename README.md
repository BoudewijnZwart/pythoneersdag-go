# pythoneersdag-go


### Slides
Om de presentatie te maken gebruiken we MARP. Dit is een kleine tool die van markdown files presentaties maakt (in de browser, pdf of powerpoint).  Installeer het met `brew install marp-cli` of `npm install -g  @marp-team/marp-cli`.
Je kan de marp server aanzetten zodat je hot reload changes meteen ziet in de browser met `marp --server --watch --theme ./rosepine.css .`. Je kan ook de presentatie genereren met `marp <markdown_file> --theme ./rosepine.css`.
